# alt-task-transfer

Bounded, explicit publication packages independent of HTTP, PostgreSQL and local
refs. A selection names roots, companions, attachment omissions and collector
attestations. Only their required record/artifact/Git closure is captured. Source
adapters supply original record envelopes and original command completion or
recovery proofs; they cannot synthesize successful execution from file presence.

Sealing verifies the entire package with the same repository/task services used
by the server, then installs a private immutable directory without overwriting a
destination. Received capture preserves the signed manifest's chunk boundaries.
Content reads enforce selection, regular files, declared length and hashes.

`Received` verifies integrity and source claims. Its `Source` implementation can
republish exact history; retention preserves original envelopes and canonical
record IDs. It never creates local requests, moves refs, changes worktrees or
authorizes execution. The caller separately authenticates the server receipt,
persists the origin and explicitly binds any continuation to a local workspace.
Partial retention after a crash is not a completed import; the caller's origin
marker must be written last. Alternate raw encodings remain in their original
packages even when a canonical record already exists locally.
