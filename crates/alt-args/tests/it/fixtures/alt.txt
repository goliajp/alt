### portable --help
exit 0
--- stdout
Transfer signed repository snapshots with explicit cutover and durable request recovery

Usage: alt portable [OPTIONS] <COMMAND>

Commands:
  export           Download a complete signed snapshot without stopping source writes
  export-status    Inspect the same immutable source export
  freeze-source    Stop source writes only at the original export watermark
  reopen-source    Explicitly remove the original source write barrier
  retire-export    Release retention for the original export; a frozen source must be reopened first
  import           Verify a local archive and stage it privately in a new empty target repository
  import-status    Query the original target intent, including a lost activation response
  activate-import  Atomically activate the original staged import under current target authority
  abandon-import   Abandon a receiving import without deleting the source or accepted history

Options:
      --json                   
      --workspace <WORKSPACE>  Operate in the named parallel workspace instead of the default one
      --request-id <HEX>       Stable request identity for a write in an existing native repository
  -h, --help                   Print help
--- stderr

### commit --help
exit 0
--- stdout
Record staged changes as a new commit

Usage: alt commit [OPTIONS]

Options:
  -m <MESSAGE>                 Commit message (with --amend, defaults to the amended commit's)
      --amend                  Replace the current branch tip with a new commit made from the index, keeping its parents and author
      --no-edit                Keep the amended commit's message (alt never opens an editor, so this is already the default without -m; accepted as in git)
      --allow-empty            Record the commit even when it changes nothing
  -n, --no-verify              Skip the pre-commit checks (secret scan, large-file warning)
      --validate               Only run the pre-commit checks on what is staged; commit nothing
      --decision <TEXT>        Record a one-line decision in the commit's metadata (up to 3)
      --meta <KEY=VALUE>       Record an extra metadata field (`key=value`, e.g. `model=…`)
      --json                   Emit the new commit/tree oids (or, with --validate, the findings) as a JSON object
      --workspace <WORKSPACE>  Operate in the named parallel workspace instead of the default one
      --request-id <HEX>       Stable request identity for a write in an existing native repository
  -h, --help                   Print help
